Live Game Predictor

The follow-up to the training project: fetch current team statistics, map them to the model inputs and calculate win probabilities for matchups.

Format
Python application
Context
Personal project
Tools
Python, NCAA API, Feature engineering

Where it started

After training models on several NCAA seasons, I wanted something I could actually use for a current matchup instead of stopping at a notebook.

The training project already defined the pregame features and model weights. This project takes those outputs and connects them to live team statistics.

How it works

The predictor requests current NCAA team data from an API, maps the returned values to the features used in training and produces a win probability for the two teams you choose.

01Choose teamsMatchup inputs
02Get statsNCAA API data
03Map featuresMatch training inputs
04PredictWin probabilities

The Python code separates concerns such as loading data, applying adjustments and generating predictions rather than leaving everything in a single script.

The tricky part

Training and prediction only agree if the feature definitions agree. A statistic can't have one meaning in the notebook and a different meaning when it comes back from an API. The code has to translate incoming data into the same feature space and use the exported model parameters consistently.

That constraint is more important than adding another button or a nicer-looking output screen.

Next improvement

I'd like to make it easier to evaluate predictions over a full current season rather than one matchup at a time. Saving predictions before tipoff and scoring them afterward would provide an honest record of how the system performs on new data.
