AI Safety Policy RAG

A local tool for asking questions about AI safety policies and comparing answers with citations from the source documents.

Format
Python application
Context
Personal project
Tools
Python, ChromaDB, Ollama, Streamlit

Why I built it

I wanted to try retrieval-augmented generation with actual source documents and more security work than a basic chatbot demo. AI policy is a good fit because the answers can change depending on which organization's policy you read.

The application lets you ask a question about AI safety policies, compare organizations and trace the answer back to the documents it used.

What happens after a question

Documents are organized by source, loaded and divided into chunks. Sentence-transformer embeddings are stored in ChromaDB. When a question comes in, the app retrieves relevant passages and gives them to a local Ollama model to produce an answer with citations.

01IngestPDF, DOCX, TXT or MD
02EmbedSentence transformers
03RetrieveChromaDB
04RespondOllama + citations

The Streamlit interface also supports comparing policies from sources including Anthropic, OpenAI and US government material.

The security work

The repository goes beyond the retrieval pipeline. It includes checks for suspicious input and prompt injection, a sliding-window rate limiter, path-traversal protection, audit logging and output sanitization.

I also added automated tests and a CI workflow. The idea was to treat untrusted inputs and document content as an engineering concern, not something the model would automatically handle safely.

The app runs locally with Ollama. That avoids a hosted model API requirement, but does not by itself establish that the system is suitable for sensitive production use.

What I learned

The main lesson was that retrieval quality and application security are separate problems. A model can produce a fluent answer and still miss the right passage, and a useful interface can still expose avoidable security risks.

If I extend it, I'd focus on stronger retrieval evaluation, document freshness and tests that check whether citations genuinely support the answer.
