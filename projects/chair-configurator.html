3D Product Configurator

An interactive office chair with real-time 3D customization, dynamic pricing and shareable configurations.

Format
React application
Context
Personal portfolio project
Tools
React, TypeScript, Three.js, React Three Fiber, CSS

The project

This is an interactive configurator for a fictional office chair. The goal was to build a product page where changes to the chair are reflected immediately in the 3D preview and in the price.

Users can rotate and zoom the model, choose upholstery and frame finishes, add or remove accessories, and see a line-by-line price breakdown. They can also copy a URL that recreates their current selections.

A model built in code

The chair uses procedural geometry instead of an externally supplied 3D model. React Three Fiber connects Three.js rendering with React components, while the scene handles lighting, shadows and camera movement.

The important part is that the chair is not a static image. Selecting a different fabric or accessory updates the geometry or materials of the model as well as the controls around it.

Keeping options and pricing in sync

TypeScript defines the available upholstery, base and accessory choices. A configuration object is the shared source of truth for the interface, rendered chair and calculated price.

The implementation starts with a $349 base chair. Two upholstery colors are included, while Terracotta and Moss add $25. A polished aluminum frame adds $55. Adjustable armrests, a headrest and soft-roll casters each have their own prices. A single pricing function totals the selected options.

These are illustrative demo prices and materials, not a real product catalog.

Shareable configurations

The selected options are serialized into URL parameters, including fabric, frame finish and accessories. On load, the app parses those parameters back into a valid configuration, falling back to defaults for unrecognized values.

That lets someone share a specific chair setup without a backend database or account system.

What it demonstrates

The project brings together a browser-based 3D scene and familiar e-commerce interactions: selection controls, dynamic pricing, responsive layout and sharing. The application also separates product rules from presentation, so the list of options and their prices can be maintained independently of the model code.

It is a front-end portfolio demonstration. It does not process payments or provide an actual store checkout.
